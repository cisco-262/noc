# OpsHome

**Practical network and IT utility apps — built for everyday monitoring, diagnostics, and infrastructure management.**

OpsHome is the central home for a growing collection of independent network and IT utility apps.

Each app focuses on a specific task, while the OpsHome website provides a single place to discover products, documentation, updates, and related resources.

## Apps

### OpsHome NOC

A mobile network operations center for monitoring homelab and infrastructure health from iPhone.

Monitor services and infrastructure including:

- Docker
- Proxmox
- Synology NAS
- Linux hosts
- Websites
- Private services
- Network and service health

Website: https://noc.opshome.run

---

### SSL Reminder

A lightweight SSL/TLS certificate monitoring utility designed to help prevent certificate expiration.

Use it to check certificates used by:

- Websites
- Services
- Apps
- APIs
- Encrypted communications

The free version can monitor up to 15 certificates at the same time.

Website: https://ssl.opshome.run

---

### WiFi Health Check

A Wi-Fi and network diagnostic utility designed to help identify situations where Wi-Fi appears connected but the actual network experience is poor.

It helps inspect different parts of the connection, including:

- Wi-Fi connectivity
- Local network communication
- DNS resolution
- Internet access
- Network quality and diagnostics

Website: https://wifi.opshome.run

---

### Domain Health Inspector

A domain inspection utility for checking important domain-related information and identifying potential configuration or expiration issues.

It can help inspect areas such as:

- Domain status
- DNS
- Registration information
- Expiration
- Email security
- TLS/SSL-related information

Website: https://domain.opshome.run

## Philosophy

OpsHome apps are designed around a few simple principles:

- Solve focused, practical IT problems
- Keep interfaces clear and easy to understand
- Make technical status easier to inspect
- Reduce unnecessary complexity
- Build useful tools for real-world network and infrastructure work
